# Core Features Overview

HiredChina provides core features covering the full recruitment lifecycle.

## Job seeker features

- **Job search**: Search by keyword, location, salary, industry, and more
- **Online resume**: Create, edit, upload, and parse resumes
- **Job application**: Apply with one click and track application status
- **Message center**: Communicate directly with employers and headhunters
- **Job recommendations**: AI-powered personalized recommendations

## Employer features

- **Job posting**: Quickly post and manage multiple jobs
- **Resume management**: View, screen, and tag candidates
- **Company profile**: Showcase company culture and open positions
- **Talent search**: Proactively discover quality candidates
- **Data analytics**: View recruitment funnel and conversion data

## AI and automation

- **AI customer service**: 24/7 online Q&A
- **AI resume parsing**: Automatically extract key resume information
- **Smart recommendations**: Two-way recommendations for jobs and talent

## Platform capabilities

- Multilingual interface
- Email and site notifications
- Mobile-responsive design
- Data privacy protection
