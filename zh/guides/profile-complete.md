# 如何完善个人档案？

一份完整的个人档案可以帮助招聘方快速了解您的背景，提高获得面试的机会。

## 步骤

1. 登录后进入「个人中心」→「我的档案」
2. 依次填写以下信息：
   - 基本信息：姓名、性别、所在城市、联系方式
   - 求职意向：期望职位、期望城市、期望薪资
   - 工作经历：公司名称、职位、工作时间、主要职责
   - 教育背景：学校、专业、学历、毕业时间
   - 技能专长：语言能力、专业技能、证书
3. 上传清晰的头像
4. 点击「保存」

## 档案完整度建议

- 完整度达到 80% 以上的档案更容易被招聘方看到
- 工作经历尽量使用量化的成果描述
- 定期更新档案，保持信息准确

## 常见问题

- 档案信息会同步到在线简历
- 您可以设置部分信息仅对投递的职位可见
- 档案中的联系方式默认对认证招聘方可见
