# 招聘方工作台使用指南

招聘方工作台是您管理职位、查看候选人和安排面试的核心界面。

## 工作台主要模块

1. **职位管理**
   - 发布新职位
   - 编辑已发布职位
   - 查看职位浏览量和申请量
   - 下架或重新发布职位

2. **候选人管理**
   - 查看收到的简历
   - 筛选和标记候选人
   - 发送面试邀请
   - 记录面试反馈

3. **公司主页**
   - 编辑公司简介和文化
   - 上传公司 Logo 和相册
   - 管理在招职位展示

4. **数据分析**
   - 查看招聘漏斗数据
   - 分析职位曝光和转化
   - 导出招聘报表

## 快速上手

1. 使用企业邮箱完成招聘方认证
2. 完善公司主页信息
3. 发布第一个职位
4. 设置团队成员和权限
