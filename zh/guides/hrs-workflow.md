# HRS 猎头系统工作流程

HRS（Headhunter Resource System）是 HiredChina 为猎头合作伙伴提供的专业招聘管理工具。

## 主要功能

1. **职位管理**
   - 接收客户委托的职位
   - 发布职位并管理候选人来源
   - 跟踪每个职位的招聘进度

2. **候选人管理**
   - 录入和编辑候选人信息
   - 标记候选人状态和匹配职位
   - 管理候选人沟通和面试安排

3. **客户管理**
   - 维护客户公司信息
   - 记录客户需求和反馈
   - 生成招聘进度报告

4. **佣金与结算**
   - 查看成功推荐记录
   - 跟踪佣金结算状态
   - 下载结算报表

## 快速上手

1. 完成猎头合作伙伴认证
2. 在系统中添加或导入候选人
3. 匹配适合的职位并推荐
4. 跟踪面试和录用流程
5. 成功入职后申请佣金结算
