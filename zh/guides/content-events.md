# 内容与活动使用指南

HiredChina 的内容与活动板块为用户提供行业资讯、招聘会和平台活动信息。

## 浏览资讯

1. 进入「资讯」或「活动」页面
2. 按分类筛选：行业动态、职场指南、政策解读、招聘会
3. 点击文章标题查看详情
4. 可以收藏感兴趣的文章或分享给朋友

## 参与活动

1. 在活动列表中查看近期活动
2. 点击「立即报名」填写报名信息
3. 报名成功后留意邮件或站内通知
4. 活动开始前会收到提醒

## 订阅功能

- 可以订阅感兴趣的内容标签
- 新内容发布时会收到推荐
- 在「通知设置」中管理订阅频率

## 内容反馈

- 如发现信息有误，可以通过文章页底部反馈
- 希望看到的话题可以提交给平台运营团队
