# 如何修改账号密码？

如果您需要修改 HiredChina 账号的密码，请按照以下步骤操作：

## 步骤

1. 登录您的 HiredChina 账号
2. 点击右上角的头像，选择「账号设置」
3. 在「安全」选项卡中，找到「修改密码」
4. 输入当前密码，然后输入新密码
5. 点击「确认修改」

## 忘记密码

如果您忘记了密码：

1. 在登录页面点击「忘记密码？」
2. 输入您注册时使用的邮箱地址
3. 查收邮件中的重置密码链接
4. 按照提示设置新密码

## 安全提示

- 建议使用包含大小写字母、数字和特殊字符的强密码
- 不要在多个网站使用相同的密码
- 定期更换密码以保护账号安全
