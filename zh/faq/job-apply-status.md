# 如何查看职位申请状态？

提交职位申请后，您可以在个人中心跟踪每一份申请的进度。

## 步骤

1. 登录账号，点击右上角头像进入「个人中心」
2. 选择「我的申请」或「申请记录」
3. 查看每条申请对应的状态标签

## 状态说明

| 状态 | 含义 |
|------|------|
| 已投递 | 申请已成功提交，等待招聘方查看 |
| 已查看 | 招聘方已查看您的简历 |
| 待沟通 | 招聘方对您感兴趣，可能即将联系 |
| 面试邀请 | 招聘方邀请您参加面试 |
| 不合适 | 招聘方认为当前职位与您的背景不匹配 |
| 已录用 | 招聘方已发出录用通知 |

## 注意事项

- 不同招聘方的反馈速度不同，请耐心等待
- 如果状态长时间未更新，可以适当通过站内信礼貌询问
- 被拒绝的申请不会影响您投递其他职位
